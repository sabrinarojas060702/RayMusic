# 🎵 RayMusic

Buscador de música de YouTube con interfaz moderna. 100% frontend.

## Uso

1. Abre `index.html` en tu navegador
2. Busca una canción
3. Haz clic en **Descargar** para ver la simulación del proceso

## Tecnologías

- HTML5 / CSS3 / JavaScript Vanilla
- YouTube Data API v3

## Seguridad de la API Key

La API Key está restringida por dominio en Google Cloud Console. Solo funciona desde los dominios autorizados.
